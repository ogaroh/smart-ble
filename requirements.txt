Flutter Development: BLE Smart Device Scanner 1. Objective The goal of this assignment is to assess your ability to build a clean, modern, and functional Flutter application that interacts with native Bluetooth Low Energy (BLE) hardware. This task simulates a common requirement in IoT and smart device development. You will build an application that can scan for nearby BLE devices, display them in a list, filter them, and connect to a selected device to discover its services and characteristics. 2. Core Requirements You will build an app with two main screens: Screen 1: BLE Scan Screen This screen is the main entry point of the app. 1. Permissions: On startup, the app must check for and request all necessary Bluetooth and Location permissions. This must include handling the new BLUETOOTH_SCAN and BLUETOOTH_CONNECT permissions for Android 12 (API 31+). 2. BT Status: The app should detect if Bluetooth is turned off on the device and prompt the user to enable it. 3. Scan Control: Include a "Start Scan" / "Stop Scan" button (or a toggle). 4. Device List: Display discovered devices in a real-time updating list as they are found. 5. Device Info: For each device in the list, you must display: a. Device Name (display "Unknown Device" if no name is advertised) b. MAC Address (or UUID) c. Signal Strength (RSSI) 6. Filtering: a. Add a text input field that allows the user to filter the device list by its advertised name. b. Add a "filter" button or dropdown that allows filtering by common device types.
